## Project Brief

# Project Brief: Faztche Social Media Base

A modern, responsive social media foundation for Android, designed to provide a seamless feed and profile experience across all device form factors.

## Features
- **Personal User Profile**: View and edit user information, including a display photo and a collection of personal posts.
- **Social Feed**: A scrollable, chronological stream of content featuring text and media updates from the community.
- **Post Creation**: A straightforward interface for users to draft, preview, and publish new social content.
- **User Discovery**: A search-driven interface to find and view other user profiles within the network.

## High-Level Technical Stack
- **Language**: Kotlin
- **UI Framework**: Jetpack Compose (Material 3)
- **Navigation**: **Jetpack Navigation 3** (State-driven navigation for modern architecture)
- **Adaptive Strategy**: **Compose Material Adaptive** (Dynamic multi-pane support for phones, tablets, and foldables)
- **Asynchrony**: Kotlin Coroutines & Flow
- **Image Loading**: Coil (Optimized for Jetpack Compose)
- **Serialization**: Kotlinx Serialization (Required for Navigation 3 type-safe routes)
